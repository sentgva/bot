# SOVSIDE bot

Telegram-бот [@sovside_bot](https://t.me/sovside_bot) с Mini App (сайт внутри Telegram):

- **Интро**: при открытии бабочка машет крыльями, проявляется надпись SOVSIDE, потом бабочка перелетает в шапку главной. Нажатие пропускает интро.
- **Главная**: кто ты и что делаешь, живые цифры Discord-сервера (участники и онлайн), услуги с ценами, как заказать, ссылки на Discord, работы и отзывы.
- **Заказ**: прайс по категориям, для позиций «за ган» можно выбрать количество, есть комментарий. Цены пересчитываются на сервере, подделать их с клиента нельзя.
- **Чат**: переписка клиента с тобой, можно отправлять фото. Клиент видит только свой чат. Ты видишь всех клиентов, их заказы и меняешь статусы (Новый / В работе / Готов / Отмена).

Всё продублировано в самом боте:

- сообщения и заказы клиентов приходят тебе в личку от бота. **Ответь реплаем**, и ответ уйдёт клиенту;
- под заказом есть кнопки статусов;
- клиент тоже может писать просто боту, сообщения попадут в тот же чат;
- если человек прямо сейчас сидит в приложении, дубль в бот не отправляется.

## Где работает

Прод: **https://sovside.vercel.app** (Vercel, проект `sovside` в команде `sdsws`).

- функция `api/index.js` обрабатывает API Mini App и вебхук Telegram (`/api/telegram`), регион fra1;
- переписки и заказы лежат в бесплатной базе Neon Postgres `sovside-db`;
- фото из чата хранятся в Vercel Blob `sovside-media`;
- сам Mini App (`webapp/`) раздаётся как статика через CDN.

При каждом продакшн-деплое сборка запускает `scripts/setup.js`: он ставит вебхук, кнопку меню и команды бота.

### Переменные окружения (Vercel → Settings → Environment Variables)

| Переменная | Что это |
| --- | --- |
| `BOT_TOKEN` | Токен от @BotFather |
| `WEBAPP_URL` | Адрес приложения, сейчас `https://sovside.vercel.app` |
| `ADMIN_ID` | Необязательно. ID админов через запятую, если нужно больше одного |
| `TELEGRAM_LINK` | Ссылка на твой Telegram для главной, необязательно |
| `COMPLETED_ORDERS_BASE` | Сколько заказов ты сделал до бота. Если больше 0, на главной вместо «в деле с 2024» будет счётчик выполненных заказов |
| `DATABASE_URL`, `BLOB_READ_WRITE_TOKEN` | Проставляются сами при подключении Neon и Blob в Storage |

После изменения переменных нужен редеплой.

### Как стать админом

Первый, кто откроет секретную ссылку `t.me/sovside_bot?start=admin-…`, станет админом, и ссылка тут же перестанет работать.
Ссылку печатает сборка на Vercel (Deployments → Build Logs) и команда `npm run setup`.
Дополнительных админов добавляй через `ADMIN_ID`.

### Деплой

```bash
npx vercel deploy --prod
```

Или подключи репозиторий в Vercel (Settings → Git), чтобы деплоилось само при пуше.

## Локальный запуск или свой сервер

Нужен Node.js 20.12 или новее.

```bash
npm install
cp .env.example .env   # и заполни
npm start
```

Без `DATABASE_URL` данные хранятся в `data/db.json`, фото в `data/uploads/`. Бот сам опрашивает Telegram, вебхук не нужен.
Если у бота уже включён вебхук на Vercel, локальный запуск откажется стартовать, чтобы не сломать прод
(`FORCE_POLLING=1`, если это действительно нужно; потом верни вебхук через `npm run setup -- --webhook`).

Для проверки на телефоне нужен https, быстрее всего так: `cloudflared tunnel --url http://localhost:3000`,
а полученный адрес впиши в `WEBAPP_URL`.

## Как поменять тексты и цены

Всё в [`src/content.js`](src/content.js): описание, ссылки, шаги, прайс.
У позиции можно указать `price: null` (договорная), `from: true` (цена «от») и `unit: 'gun'` (цена за ган, с выбором количества).
После правки перезапусти бота.

Картинки в `webapp/assets/`: `butterfly.webp` (бабочка из логотипа, на прозрачном фоне) и `cover.jpg` (обложка в `/start`).
Шрифт логотипа: Unbounded 300, лежит в `webapp/assets/fonts/`.

## Устройство

```
api/index.js    вход на Vercel
src/
  index.js      локальный запуск: сервер + бот с опросом Telegram
  app.js        сборка приложения
  bot.js        команды и сообщения в Telegram, настройка вебхука
  chat.js       переписка клиент ↔ админ, заказы, уведомления
  server.js     HTTP API для Mini App и вебхук
  auth.js       проверка подписи Telegram (initData)
  db.js         данные бота
  store.js      хранилище: Postgres (Neon), Redis (Upstash) или файл
  media.js      фото: Vercel Blob или папка data/uploads
  content.js    тексты, ссылки, прайс
  discord.js    цифры Discord-сервера (кэш на 10 минут)
scripts/setup.js  вебхук, кнопка меню и команды бота
webapp/         сам Mini App: index.html, styles.css, app.js
test/           тесты: npm test (с TEST_DATABASE_URL заодно проверяется Postgres)
```

Каждый запрос из Mini App подписан Telegram, сервер проверяет подпись токеном бота. Поэтому чужой чат нельзя открыть, подставив чужой ID, а админские действия доступны только ID из `ADMIN_ID`.

## Безопасность

- `.env`, `data/` и `.vercel/` в `.gitignore`, токен в репозиторий не попадает. На Vercel токен лежит как sensitive-переменная.
- Секрет вебхука и секретная ссылка админа выводятся из токена. После `/revoke` обнови `BOT_TOKEN` и сделай редеплой, старые перестанут работать.
- Если токен где-то засветился, выпусти новый: @BotFather → `/revoke`, и обнови `.env`.
