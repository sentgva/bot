# SOVSIDE bot

Telegram-бот [@sovside_bot](https://t.me/sovside_bot) с Mini App (сайт внутри Telegram):

- **Интро**: при открытии бабочка машет крыльями, выезжает надпись SOVSIDE, потом бабочка перелетает в шапку главной. Нажатие пропускает интро.
- **Главная**: кто ты и что делаешь, живые цифры Discord-сервера (участники и онлайн), услуги с ценами, как заказать, ссылки на Discord, работы и отзывы.
- **Заказ**: прайс по категориям, для позиций «за ган» можно выбрать количество, есть комментарий. Цены пересчитываются на сервере, подделать их с клиента нельзя.
- **Чат**: личная переписка клиента с тобой, можно отправлять фото. Клиент видит только свой чат. Ты видишь всех клиентов, их заказы и меняешь статусы (Новый / В работе / Готов / Отмена).

Всё продублировано в самом боте:

- сообщения и заказы клиентов приходят тебе в личку от бота. **Ответь реплаем**, и ответ уйдёт клиенту;
- под заказом есть кнопки статусов;
- клиент тоже может писать просто боту, сообщения попадут в тот же чат;
- если человек прямо сейчас сидит в приложении, дубль в бот не отправляется.

## Запуск

Нужен Node.js 20.12 или новее.

```bash
npm install
cp .env.example .env   # и заполни
npm start
```

### Что вписать в `.env`

| Переменная | Что это |
| --- | --- |
| `BOT_TOKEN` | Токен от @BotFather |
| `ADMIN_ID` | Твой Telegram ID. Запусти бота, напиши ему `/id`, впиши число, перезапусти |
| `WEBAPP_URL` | Публичный **https**-адрес, где работает сервер. Без него кнопка приложения не появится |
| `TELEGRAM_LINK` | Ссылка на твой Telegram (канал или личка) для главной, необязательно |
| `COMPLETED_ORDERS_BASE` | Сколько заказов ты сделал до бота. Если больше 0, на главной вместо «в деле с 2024» будет счётчик выполненных заказов |
| `PORT` | Порт сервера, по умолчанию 3000 |

При старте бот сам ставит кнопку меню «SOVSIDE», которая открывает приложение.

### Где взять https

Telegram открывает Mini App только по https.

**Быстро проверить** (адрес меняется при каждом запуске):

```bash
npm start
cloudflared tunnel --url http://localhost:3000
# вписать выданный https://….trycloudflare.com в WEBAPP_URL и перезапустить бота
```

**Насовсем**: VPS + домен + [Caddy](https://caddyserver.com), он сам выпускает сертификат:

```
sovside.example.com {
    reverse_proxy localhost:3000
}
```

Бот держи запущенным через `pm2 start npm --name sovside -- start` или systemd.
Папка `data/` хранит переписки, заказы и фото. Её нельзя терять, делай бэкапы.

## Как поменять тексты и цены

Всё в [`src/content.js`](src/content.js): описание, ссылки, шаги, прайс.
У позиции можно указать `price: null` (договорная), `from: true` (цена «от») и `unit: 'gun'` (цена за ган, с выбором количества).
После правки перезапусти бота.

Картинки в `webapp/assets/`: `butterfly.webp` (бабочка из логотипа, на прозрачном фоне) и `cover.jpg` (обложка в `/start`).

## Устройство

```
src/
  index.js      запуск: сервер + бот
  bot.js        команды и сообщения в Telegram
  chat.js       переписка клиент ↔ админ, заказы, уведомления
  server.js     HTTP API для Mini App и раздача статики
  auth.js       проверка подписи Telegram (initData)
  db.js         хранилище в data/db.json
  content.js    тексты, ссылки, прайс
  discord.js    цифры Discord-сервера (кэш на 10 минут)
webapp/         сам Mini App: index.html, styles.css, app.js
test/           тесты: npm test
```

Каждый запрос из Mini App подписан Telegram, сервер проверяет подпись токеном бота. Поэтому чужой чат нельзя открыть, подставив чужой ID, а админские действия доступны только ID из `ADMIN_ID`.

## Безопасность

- `.env` и `data/` в `.gitignore`, токен в репозиторий не попадает.
- Если токен где-то засветился, выпусти новый: @BotFather → `/revoke`, и обнови `.env`.
